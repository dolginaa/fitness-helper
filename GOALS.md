# Цели (GOALS)

- [x] Бекап: ручная выгрузка (`/export`, кнопка в меню), импорт из `.zip`, еженедельный opt-in бекап (`/backup_on`)
- [x] График при выборе упражнения в тренировке (макс. вес за сессию)
- [x] `/history6m` и `/workout` по дате — история за полгода и детали тренировки
- [x] График прогресса по группе мышц (`/progress`, кнопка «График прогресса»)
- [x] Ввод подхода одним сообщением (`10 50`, несколько через запятую), кнопки «ещё такой же» и «убрать последний»
- [x] Подходы сохраняются сразу; незавершённую тренировку можно продолжить, пустая не сохраняется
- [x] Навигация кнопками без тупиков: главное меню, «назад» на каждом экране, меню команд
- [x] Своё упражнение прямо из тренировки
- [x] История с группами мышц и листанием, итог тренировки с тоннажем
- [x] Даты в часовом поясе пользователя (`TZ`)
- [x] Графики, читаемые в чате: макс. вес + объём по упражнению, сетка маленьких графиков по группе
- [x] Два транспорта до Telegram: Bot API (SOCKS5/HTTP‑прокси) и MTProto (MTProto‑прокси)
- [x] Mini App — второй интерфейс к тем же данным (тренировка, история, прогресс)
- [ ] Причесать список упражнений (есть те, которые отличаются только написанием). При этом нельзя потерять существующие записи тренировок
- [ ] Поддержать разные категории упражнений: например, подтягивания можно делать не только в гравитроне, выставляя вес, но и с резинкой, в таком случае хотелось бы выбирать цифру сопротивления резинки (от 1 до 10, например, где 10 - самая толстая резинка); так же есть, также есть, например, отжимания, в которых упражнение делается с собственным весом
- [ ] в конце занятия можно было бы выводить какую-то доп полезную информацию помимо тоннажа
